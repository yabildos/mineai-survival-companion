# MineAI Blueprints

This folder contains a few small, project-authored examples for the public
`build_structure` tool.

## Current Rules

- Coordinates are relative to a user-selected origin.
- Inspect the build area and materials before placing blocks.
- Keep each `build_structure` request bounded and verify placement in-world.

## Workflow

1. Review a project-authored example.
2. Choose a safe, clear footprint in the current world.
3. Confirm the requested blocks and materials with the user.
4. Send the bounded block list to `build_structure` and inspect the result.

This is a reference collection, not a promise that every example is suitable
for every Minecraft version or site.
